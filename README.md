Devil Pact – s&box

A multiplayer roguelite game developed in just one week by a team of 2 programmers and 2 artists using s&box.

I was responsible for the overall game architecture and networking, including the multiplayer framework, synchronized game state, round management, and core game loop. I also implemented the networked UI, ensuring that gameplay information and round progression remained synchronized across all connected players.

My contributions:

* Designed and implemented the overall game architecture
* Implemented the complete round and game loop system
* Managed player-state and game-state synchronization
* Integrated and coordinated the different gameplay systems within s&box

The project was built from scratch under a one-week development constraint, with a strong focus on multiplayer architecture, synchronization, and delivering a playable experience within a very limited timeframe.
